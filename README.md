 Community Notice Board 
 Features
- Post New Notice board: Add title, category, description and contact details
- 4 Categories: Event, For Sale, Lost & Found, Help Needed
- Filter Notices: View notices by category using filter buttons
- Responsive Design: Works on both mobile and desktop
- Form Validation: Ensures all fields are filled before posting

 Technologies Used
- HTML5
- CSS3
- JavaScript
- Hosted on GitHub Pages

 How to Use
1. Click on `+ Add Notice` button
2. Fill in Title, Category, Description and Contact
3. Click `Post Notice` to add it to the board
4. Use filter buttons to view specific category notices
